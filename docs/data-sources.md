## 都市を追加するときの運用

1. 追加する都市のPLATEAUデータページを開き、**そのデータセット固有のライセンス条件**を
   確認する（`requirements.md` §4.2が自ら注意している通り、データ提供元によって条件が
   異なる場合がある。CC BY 4.0が原則だが機械的に決め打ちしない）。
2. 上の表に1行追加する（データセットID・自治体名・取得元URL・ライセンス・確認日）。
3. ゲーム内の出典表示画面に、追加した都市の分の記載が反映されているか確認する。
